# Agency Platform

A software development agency platform for showcasing services,
attracting clients, and managing projects collaboratively.

## Applications

- frontend: Next.js and TypeScript
- backend: FastAPI and Python
- database: PostgreSQL

## Main Features

- Public agency website and portfolio
- Client inquiries and project requests
- Team dashboard and task management
- Project deadlines and file sharing
- Quotes, invoices, and payment tracking
- Client portal for progress updates and deliverables
